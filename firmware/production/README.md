# ESP32-S3 集成候选程序（禁止生产使用）

这是实际设备任务的开发候选版，不是可投产的完整交付。按键、NVS 和同步规划由 Arduino loop 独占；Wi-Fi、可信时间及 HTTPS 由独立 FreeRTOS 任务串行运行，使用非等待邮箱交接。启动检查本地配置、证书解析、NVS、互斥锁、邮箱和任务创建；失败时不自动清空数据。存储或状态故障会停止计数及后续网络任务。串口状态不输出 Wi-Fi 信息、设备密钥或生产单编号。

CI 使用空配置编译（该配置运行时必须拒绝启动），不得把其作为生产或真实联网凭据。实际使用需要在本机将 `src/config.example.h` 复制为 `src/config.local.h`，并**通过安全渠道**配置测试项目 Wi-Fi、设备 ID、设备密钥和经过独立核验的 CA。`config.local.h` 已被 Git 忽略，不得发送到聊天或提交 Git。固件使用设备私钥及 Wi-Fi 密码：本地源代码和 Flash 均含敏感信息，非加密设备可能被读取。

真实服务设备迁移和时间证明端点尚未部署，正式页面的设备功能尚未开放；本程序不能连接目前正式生产流程。CA 真实性、轮换、时间窗口所需硬件时钟漂移保证、真实 HTTP 响应、线程栈与看门狗、断电/NVS 高速写入耐久、冻结与断网行为均未在真机验证。串口仅供诊断，无独立可见的容量/故障指示；1 秒实时目标和 2 秒续约在真实网络中未得到保证。候选程序不得投产，也不得清除旧 NVS 以掩盖读取失败。

构建候选：在本地配置完毕后使用 `pio run -d firmware/production`。在隔离测试环境、备份现有固件与数据后方可烧录。切勿在生产设备上直接验证。
