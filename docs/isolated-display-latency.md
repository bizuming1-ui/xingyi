# 隔离测试站：设备显示测速（实验功能）

仅限电脑端支持 Web Serial 的 Chrome / Edge、HTTPS 隔离站、当前设备测试固件。
不改变设备计数、上传、绑定、确认或生产单。浏览器只读取串口，不向串口写入。
浏览器和 VS Code 不能同时占用 COM21；打开串口可能使板卡复位，断开或离开页面会尝试释放串口。

要求仅一块连接中的设备、页面选中同一已绑定订单、没有其他人或设备操作，没有未上传计数，测试时不冻结、不确认、不改绑。无法通过串口独立验证这些条件，需操作者保证。用于隔离测试，操作会产生真实测试计数。

1. 关闭 VS Code 的串口监视器，保持开发板 USB 与网络连接。
2. 在电脑浏览器打开隔离测试站、登录并进入对应订单，点击“显示测速（测试）”，选择“连接 COM21”，在浏览器授权界面选择正确端口。
3. 等待 WIFI/TIME 恢复。短按一次进行校准，等待上传确认、本地 PENDING 为零、服务器读取在确认之后开始、设备冻结状态为无、并收到监视器丢失计数后，“准备测试一次”才可点击。
4. 点击“准备测试一次”，仅短按一次。系统自动等待“现在”框增加 1，显示并记录估算毫秒；期间不可再次按键、确认、切换订单或让其他人操作。
5. 可下载脱敏 JSON；只包含计算结果和网页变化数，不包含串口原文、设备 ID、Wi-Fi 或密钥。离开页面或点击“断开串口”释放端口后，才能再次使用 VS Code。

测量起点是**浏览器收到固件 COUNT 行的时间**，终点是 React 更新后的**首个 requestAnimationFrame 回调时间**，均由同一浏览器性能时钟计量；它们不等同于物理按键时间或实际显示器完成扫描的时间。COUNT 每 200ms 限速且可能被跳过，USB/操作系统/浏览器调度及帧回调增加不确定性，因此结果不能视为真实端到端精确值或可靠上下界，无法证实具体点击与服务器数变化的一一对应。

测速在多次计数、网页值变化异常、设备掉线或可信时间失效、确认冻结、浏览器后台、时钟回退、日志丢失数增加、读取错误或超时时中止。丢失计数有报告间隔，可能在结果之后才发现丢失；未报丢失也不能证明日志完整。若因缓冲丢失收不到 COUNT、M1/M3、WIFI、FREEZE、MON 任一校准行，按钮会保持不可用，不能靠猜测补齐。浏览器刷新或关闭后测量记录不保存；不支持 Web Serial 的设备不显示入口。旧固件、不同串口文本格式、代理或扩展干扰也可能使测速不可用。
